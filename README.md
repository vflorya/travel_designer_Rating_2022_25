# Рейтинг горнолыжных курортов России — Travel Designer

Проект представляет собой воспроизводимый расчет рейтинга 32 горнолыжных курортов России на основе открытых данных. 
Итоговый результат — аналитический дашборд в Yandex DataLens, показывающий потенциал курортов, их сильные и слабые стороны, а также качество исходных данных.

## 📁 Структура проекта
* `data/raw/` — исходные файлы (выгрузки ЕМИСС, Росстат, OurAirports) и ответы API (OSM, Open Meteo). **Не редактируются вручную.**
* `data/processed/` — очищенные и подготовленные таблицы (`model_data.json`), а также итоговые выгрузки для DataLens (`rating_result.csv`, `rating_full.csv` и др.).
* `src/` — скрипты для сбора данных, очистки, агрегации и расчета баллов.
* `notebooks/` — исследовательские ноутбуки (аудит данных, проверка формул).
* `README.md` — инструкция по запуску и описание проекта.

## ⚙️ Как воспроизвести расчет

Для работы требуется **Python 3.10+** и установленные библиотеки:
pip install -r requirements.txt

**Шаг 1. Аудит и сборка данных**
Откройте ноутбук `notebooks_14_01_audit_resorts.ipynb` и выполните все ячейки. Он проверит справочник курортов и соберет региональные метрики.

**Шаг 2. Расчет баллов**
Откройте `notebooks_14_02_scoring.ipynb` для проверки формул нормализации и сверки с эталоном.

**Шаг 3. Сборка финального рейтинга и выгрузка**
Откройте `notebooks_03_rating (6).ipynb`, выполните все ячейки сверху донизу. Последняя ячейка сгенерирует 4 CSV-файла в папке `data/processed/` для загрузки в DataLens.

## 🗂 Файлы для загрузки в DataLens
В папке `data/processed/` сформированы следующие витрины:
* `rating_result.csv` — главная таблица рейтинга (для 1-го слайда).
* `rating_full.csv` — полная витрина с 13 баллами и 5 компонентами (для профиля и сравнения).
* `rating_quality.csv` — данные о качестве (флаги, наличие цены).
* `resorts_coordinates.csv` — координаты для карты.
*Соединение всех таблиц в DataLens происходит по ключу `resort_id`.*

6. **Цены собраны не для всех.** На момент сбора цены доступны для 9 из 32 курортов (28%). Для остальных ценовой балл заменен на 50.
7. **Проблемы с координатами.** 18 из 32 курортов имеют флаг `manual_review_required` (координата указывает на соседний объект, а не на центр курорта). 8 курортов имеют флаг `nearby_feature_proxy`. Это может влиять на расчет OSM и расстояния до аэропорта.

## 🖥 Структура дашборда
1. **Рейтинг + Карта** — сводная таблица 32 курортов, фильтры по региону и категории.
2. **Профиль курорта** — радар из 5 компонентов, детализация по 13 баллам и автоматический текстовый вывод.
3. **Сравнение** — сопоставление двух курортов по 5 компонентам и 13 баллам.
4. **Качество данных** — KPI по пропускам, сортировка по уверенности, расшифровка флагов.
