# Рейтинг горнолыжных курортов России — Travel Designer

Проект представляет собой воспроизводимый расчет рейтинга 32 горнолыжных курортов России на основе открытых данных. 
Итоговый результат — аналитический дашборд в Yandex DataLens, показывающий потенциал курортов, их сильные и слабые стороны, а также качество исходных данных.

## 📁 Структура проекта
* `data/raw/` — исходные файлы (выгрузки ЕМИСС, Росстат, OurAirports) и ответы API (OSM, Open Meteo). **Не редактируются вручную.**
* `data/processed/` — очищенные и подготовленные таблицы (`model_data.json`), а также итоговые выгрузки для DataLens (`rating_result.csv`, `rating_full.csv` и др.).
* `src/` — скрипты для сбора данных, очистки, агрегации и расчета баллов.
* `notebooks/` — исследовательские ноутбуки (аудит данных, проверка формул).
* `README.md` — инструкция по запуску и описание проекта.

📊 Источники данных
Согласно ТЗ, в проекте использованы следующие источники:

ЕМИСС (62157, 62489): Данные по туристским поездкам и ночёвкам по регионам РФ за 2022–2025 гг.

OpenStreetMap (Overpass API): Инфраструктура (трассы, подъёмники, отели, питание) в радиусе 6 км от координат курорта.

Open Meteo (ERA5 Land): Дневная температура и снегопад за 5 зимних сезонов (2021/22–2025/26).

OurAirports: Ближайшие коммерческие аэропорты и расстояние до них по прямой (формула Haversine).

Ручной сбор: Цены на взрослые дневные ски-пассы с официальных сайтов курортов.

Wikipedia / Wikidata: Проверка названий и координат курортов.

📈 Методика расчета
Рейтинг строится на основе 13 показателей, сгруппированных в 5 компонентов:

Спрос (40%): Поездки, рост турпотока, средняя длительность.

Инфраструктура (25%): Трассы, подъёмники, размещение, питание/достопримечательности (по OSM).

Зима (20%): Снежные дни, морозные дни, сезонный снегопад.

Доступность (10%): Расстояние до аэропорта, локальный транспорт.

Цена (5%): Средняя стоимость дневного ски-пасса.

Итоговый индекс (popularity_score) нормализован от 0 до 100.
Рядом с рейтингом рассчитывается confidence_score — метрика уверенности в данных (полнота полей, наличие цены, точность координат, отсутствие OSM-overlap).

⚠️ Ограничения модели
Согласно ТЗ, при использовании рейтинга необходимо учитывать следующие ограничения:

Региональный поток ≠ посещаемость курорта. Данные Росстата относятся ко всему субъекту РФ. Все курорты одного региона получают одинаковый балл спроса.

Полнота OSM различается. В одних регионах картографирование активнее, в других — объектов меньше. Это влияет на баллы инфраструктуры.

Радиус 6 км ≠ границы курорта. В Красной Поляне и Приэльбрусье радиусы пересекаются, поэтому баллы инфраструктуры для этих курортов не независимы (помечены флагом OSM radii overlap).

ERA5 сглаживает рельеф. Данные сетки (~25 км) не заменяют метеостанцию на склоне.

Расстояние до аэропорта по прямой. Не учитывает время в пути и качество дорог.

Цены собраны не для всех. На момент сбора цены доступны для 9 из 32 курортов (28%). Для остальных ценовой балл заменен на среднее значение (50).

Min-max нормализация зависит от выборки. При добавлении 33-го курорта баллы остальных могут измениться.

Веса — рабочая гипотеза. Сценарии с изменением весов показывают чувствительность, но не доказывают причинно-следственные связи.

🏷️ Флаги качества данных
В дашборде (вкладка «Качество данных») используются следующие флаги:

check coordinates / coordinates are proxy — координата является приблизительной (взята по ближайшему объекту), требует ручной проверки.

OSM radii overlap — радиус 6 км пересекается с соседним курортом, возможен двойной учет объектов.

нет цены — цена не найдена, ценовой балл заменен на 50.**
