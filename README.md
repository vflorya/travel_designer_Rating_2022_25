# Рейтинг горнолыжных курортов России — Travel Designer
<img width="612" height="260" alt="image" src="https://github.com/user-attachments/assets/774f4ffa-5fff-47dc-ad8f-03fe345aa59e" />

Воспроизводимый расчёт рейтинга 32 горнолыжных курортов России на основе открытых данных. Задача — понять, какие курорты стоит первыми добавить в каталог Travel Designer, и показать для каждого места: из каких данных оно получено, какие допущения использованы и насколько мы уверены в исходных данных.

**Главный результат — не цифра рейтинга сама по себе, а воспроизводимый расчёт.** Другой аналитик должен взять `data/raw/`, выполнить команды из этого README и получить тот же результат (±0.2 балла — допуск из ТЗ).

## 🧮 Методика

13 показателей сгруппированы в 5 компонентов. Веса:

| Компонент | Вес | Показатели |
|---|---:|---|
| Спрос | 40 | поездки (25) + рост (10) + длительность (5) |
| Инфраструктура | 25 | трассы (10) + подъёмники (7) + размещение (5) + сервисы (3) |
| Зима | 20 | снежные дни (8) + морозные (6) + снегопад (6) |
| Доступность | 10 | аэропорт (8) + транспорт (2) |
| Цена | 5 | средняя цена ски-пасса |

Нормализация: log min-max для поездок, OSM и снегопада; min-max для снежных/морозных дней; обратная шкала для аэропорта и цены. Пропуск цены → `price_score = 50`, курорт не удаляется. `confidence_score` не входит в индекс и не влияет на место.

## ⚠️ Ограничения

1. Региональный турпоток относится ко всему субъекту РФ, а не к курорту — все курорты одного региона получают одинаковый балл спроса.
2. Полнота OSM различается между регионами.
3. Радиус 6 км не совпадает с реальными границами курорта; в Красной Поляне и Приэльбрусье радиусы пересекаются.
4. ERA5 (разрешение ~25 км) сглаживает рельеф и не заменяет метеостанцию на склоне.
5. Расстояние до аэропорта — по прямой, не равно времени трансфера.
6. Цена ски-пасса есть только у 9 из 32 курортов, меняется по дням.
7. Min-max зависит от состава выборки: после добавления нового курорта баллы остальных изменятся.
8. Веса — рабочая гипотеза, а не доказанная причинность.
9. Росстат и ЕМИСС за 2025 год могут пересматриваться.

Дополнительно: 18 из 32 курортов имеют флаг `manual_review_required` (координата указывает на соседний объект), 8 — `nearby_feature_proxy`.

## 📚 Источники

- ЕМИСС 62157 (поездки) и 62489 (ночёвки) — без ключа
- Росстат «Туризм» — КСР, выручка, ВДС
- OpenStreetMap Overpass API — инфраструктура в радиусе 6 км
- Open-Meteo ERA5 — климат, 2021-11-01 — 2026-04-30
- OurAirports — координаты и IATA
- Wikipedia и Wikidata — проверка координат
- Roschart — дополнительный слой Росстата

Даты сбора — 14/09/2026 (в `data/raw/resort_open_data.json` → `collectedAt`)

## 🎯 Ключевые выводы

- Сильнее всего на рейтинг влияют `region_trips` (54% дисперсии), `region_growth` (11%) и `pistes` (7%).
- Топ-4 устойчив к сценариям весов (+20% климат, +20% доступность).
- Гипотеза про зимнюю долю КСР не подтвердилась: топ-10 не меняется, только Шерегеш и Игора (7↔8).
- Курорты с высоким индексом и низкой уверенностью (Игора, Горный воздух, Бобровый лог, Губаха) — требуют ручной проверки перед добавлением в каталог.
